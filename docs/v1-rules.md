# V1 对战规则（冻结版）

> 本文档是 V1 的规则基准。实现核心引擎时以本文为准；改动规则先改本文再改代码。
> 目标：有游戏王味道，但不陷入现代规则复杂度。

## 1. 基本盘

- 1v1，双方 8000 LP。
- 主卡组 40～60 张；额外卡组最多 15 张，V1 只放融合怪兽（仪式怪兽放主卡组）。
- 同名卡在卡组（含额外）中最多 3 张；标记 `LIMIT_1` 的卡整个卡组只能放 1 张。
- 起手 5 张，先攻第一回合不抽牌（可选简化：先攻也抽，二选一，实现时固定一个即可）。
- 每回合的抽牌阶段抽 1 张。

## 2. 场地

- 每名玩家：5 个怪兽区、5 个魔法陷阱区、1 个卡组区、1 个额外卡组区、1 个墓地、1 个除外区、1 个场地魔法区（共用每边 1 格）。
- 怪兽表示形式：攻击表示 / 防守表示（盖防守）/ 盖攻击不允许（简化）。

## 3. 回合流程

```
抽牌阶段 → 准备阶段 → 主要阶段1 → 战斗阶段 → 主要阶段2 → 结束阶段
```

先攻第一回合不能进入战斗阶段。

## 4. 怪兽的出场方式

| 方式 | 说明 |
|---|---|
| 通常召唤 | 每回合 1 次，攻击/防守表示，正面出场 |
| 盖放 | 算通常召唤次数，背面防守表示 |
| 反转召唤 | 每回合每只 1 次，背面怪兽翻成正面攻击表示 |
| 祭品召唤 | 5～6 星：1 只祭品；7 星以上：2 只祭品。不限次数（占用当回合的通常召唤次数） |
| 特殊召唤 | 卡牌效果或融合/仪式流程，不限次数 |
| 反转 | 盖放怪兽被翻成正面时（战斗/效果），发动翻转效果 |

## 5. 战斗

- 每只怪兽每回合攻击 1 次。攻击宣言指定对方 1 只怪兽；对方场上无怪兽时可以直接攻击玩家。
- 正面攻击表示 vs 正面攻击表示：ATK 高者胜，差值作为战斗伤害扣给败方。
- 正面攻击 vs 防守表示：ATK > DEF 时防守方被破坏，无战斗伤害（贯穿除外）；ATK < DEF 时攻击方受差值伤害；相等则无事发生。
- 盖放怪兽被攻击时先翻开（触发反转效果），再按正面数值结算。
- 贯穿（PIERCE）：攻击防守表示怪兽并击破时，把超出 DEF 的部分作为伤害结算。
- 战斗破坏的怪兽送去墓地。0 攻怪兽被攻击表示怪兽攻击时，受全额 ATK 伤害。

## 6. 魔法与陷阱

- 魔法种类（V1）：通常、速攻、永续、装备、场地、仪式。
- 陷阱种类（V1）：通常、反击、永续。
- 魔法盖放后当回合不能发动（经典规则）。
- 陷阱盖放后必须等一回合才能发动。
- 装备魔法挂在正面怪兽上；怪兽离场或变成背面时装备破坏。
- 场地魔法双方共用 1 格，新的覆盖旧的。

## 7. 速度与连锁

| 速度 | 卡种 |
|---|---|
| 1 | 通常/装备/场地魔法、仪式魔法、怪兽起动效果 |
| 2 | 速攻魔法、全部陷阱、怪兽诱发即时效果 |
| 3 | 反击陷阱 |

连锁规则（V1 简化版）：

1. 一方发动卡牌/效果 → 对手可以响应，形成连锁堆栈。
2. 响应卡的_speed 必须 ≥ 被响应卡的_speed。
3. 双方连续放弃响应后，堆栈从最后一张开始逆序结算。
4. 对象在**发动时**指定，结算时对象可能已离场 → 该段效果空发（fizzle），不阻断后续结算。

V1 不实现：错过时点、效果处理中途新触发、复杂伤害步骤分阶裁定、及个别卡的特殊例外。

## 8. 区域

- 墓地：被破坏/使用完的卡默认去墓地。
- 除外区：被除外的卡，V1 不做回收除外区卡的效果（除个别 V1 卡直接从除外区拉人时另行标注）。
- 手牌上限：结束阶段手牌超过 6 张的，弃到 6 张。

## 9. V1 明确不做

- 同调 / 超量 / 灵摆 / Link。
- 衍生怪兽（Token）、掷硬币、放指示物。
- 一张卡 4～5 个独立效果、大量"一回合一次"的不同名称限制。
- 连锁中除外自身再返回、根据特殊召唤方式变化的效果。
- 同时改写规则+区域+召唤条件的卡。
- Exodia 特殊胜利等特殊胜利条件。
